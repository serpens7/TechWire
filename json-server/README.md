# json-server/db.json

Это больше **не** работающий бэкенд — json-server заменён на `server/`
(NestJS + Prisma + PostgreSQL).

Файл `db.json` остался как **исходные данные для сида**: `server/prisma/seed.ts`
читает его и наполняет базу. Именно поэтому он лежит в git и его не стоит
удалять — без него базу нечем восстановить.

Что важно про эти данные:

- **Идентификаторы не сплошные** — статьи имеют id 1, 3, 18…51 (всего 36 штук).
  На них завязаны e2e-тесты и моки сторисов, поэтому сид сохраняет их как есть.
- **Пароли лежат открытым текстом** (`admin`/`123`, `user2`/`321`). В базу они
  попадают только через bcrypt; сами пары не менялись, чтобы не ломать e2e.
- **`createdAt` — строка `"DD.MM.YYYY"`.** В базе это настоящая дата: json-server
  сортировал такие строки лексически, то есть сортировка по дате работала
  неверно.
- **`username` и `avatar` дублируются** в `users` и в `profile`. В базе они
  живут только у пользователя, в ответе API склеиваются обратно.
- **`posts`** фронтом не используется и в базу не переносится.

Восстановить базу из этого файла:

```bash
npm --prefix server run db:seed          # добавить недостающее (идемпотентно)
npm --prefix server run db:seed:fresh    # очистить и засеять заново
npm --prefix server run db:verify        # сверить содержимое базы с db.json
```
